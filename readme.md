## 📖 Sobre o projeto

O **S6_R1_AT1** é uma atividade desenvolvida utilizando **PHP**, com o objetivo de praticar conceitos de programação e desenvolvimento web.

O projeto possui o arquivo `index.php`, que reúne a implementação desenvolvida durante a atividade.

## 💻 O que foi desenvolvido

Foi desenvolvida uma aplicação utilizando **PHP**, trabalhando a criação de uma página web com código executado pelo servidor.

Durante a atividade foram praticados:

* Criação e organização de arquivos PHP;
* Estrutura básica da linguagem PHP;
* Utilização de PHP em páginas web;
* Exibição de informações no navegador;
* Execução de PHP em servidor local;
* Organização e versionamento do projeto com Git e GitHub.

## 🛠️ Tecnologias

* 🐘 **PHP** — desenvolvimento da aplicação;
* 🌐 **HTML5** — estrutura da página;
* 🔧 **Git** — controle de versões;
* 🐙 **GitHub** — armazenamento do projeto.

## ▶️ Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/Cristantenicollas/PHP.git
```

### 2. Entre na pasta

```bash
cd PHP/S6_R1_AT1
```

### 3. Inicie o servidor PHP

```bash
php -S localhost:8000
```

Depois, acesse no navegador:

```text
http://localhost:8000
```
