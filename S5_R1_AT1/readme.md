# S5_R1_AT1 — Fundamentos de PHP

## 📚 Sobre o projeto

Este projeto foi desenvolvido como uma atividade prática de **PHP**, com o objetivo de aplicar conceitos básicos da linguagem e entender como um programa pode armazenar informações, realizar verificações e apresentar resultados.

## 🎯 O que foi desenvolvido

No arquivo `index.php`, foi criado um pequeno programa que simula informações de uma empresa.

Foram utilizados:

* **Variáveis** para armazenar informações da empresa;
* **Tipos de dados**, como `string`, `integer` e `boolean`;
* **`echo`** para exibir informações na tela;
* **`if`, `elseif` e `else`** para verificar a quantidade de funcionários;
* **Operador ternário** para verificar se a empresa está ativa;
* **`switch/case`** para identificar o dia da semana e informar se a empresa está aberta ou fechada;
* **`break`** para interromper cada caso do `switch`.

## 💻 Funcionamento

O programa utiliza os valores armazenados nas variáveis e realiza verificações para gerar as respostas.

A quantidade de funcionários é analisada por meio de condições. O programa também verifica o status da empresa e utiliza o número correspondente ao dia da semana para informar se ela está aberta ou fechada.

## 📥 Como clonar o projeto

Para baixar o projeto do GitHub para o computador, é necessário ter o **Git** instalado.

### 1. Abra o terminal

No Windows, pode ser utilizado o **Git Bash**, PowerShell ou Prompt de Comando.

### 2. Escolha uma pasta

Entre na pasta onde deseja guardar o projeto. Por exemplo:

```bash
cd Desktop
```

### 3. Faça o clone do repositório

Execute:

```bash
git clone https://github.com/Cristantenicollas/PHP.git
```

Esse comando irá baixar todo o repositório **PHP** para o computador.

### 4. Entre na pasta do projeto

```bash
cd PHP
```

Depois, entre na pasta da atividade:

```bash
cd S5_R1_AT1
```

Agora você estará dentro da pasta que contém o arquivo `index.php`.

## ▶️ Como executar

Com o PHP instalado, dentro da pasta `S5_R1_AT1`, execute:

```bash
php -S localhost:8000
```

Depois, abra o navegador e acesse:

```text
http://localhost:8000
```

O navegador irá mostrar o resultado do programa.
