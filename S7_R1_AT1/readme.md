# 🐘 S7_R1_AT1 — Arrays em PHP

## 📌 Sobre o projeto

Este projeto foi desenvolvido em **PHP** com o objetivo de praticar o uso de **arrays** e diferentes formas de percorrer e acessar seus dados.

Durante a atividade, foram trabalhados arrays simples, arrays associativos, matrizes e estruturas de repetição como `for` e `foreach`.

## 🚀 O que foi desenvolvido

### 🔹 Array simples

Foi criado um array chamado `$trabalhadores`, contendo nomes de funcionários. Os dados são exibidos utilizando:

* `for` — percorre o array através dos índices.
* `foreach` — percorre diretamente cada valor armazenado.

### 🔹 Array associativo

Foi criado o array `$colaborador`, utilizando **chaves e valores** para armazenar informações como:

* Nome
* Idade
* Cargo

As informações são acessadas através de suas respectivas chaves.

### 🔹 Matriz de arrays associativos

Também foi criada a variável `$colab`, contendo vários colaboradores, cada um com seu nome, idade e cargo.

O projeto demonstra duas formas de acesso:

* Acesso direto a um colaborador através do índice.
* Uso do `foreach` para percorrer todos os colaboradores e exibir suas informações.

## 🛠️ Tecnologias utilizadas

* **PHP**
* **HTML** para algumas tags utilizadas na exibição dos resultados.
* **Git/GitHub** para versionamento e armazenamento do projeto.


## 🎯 Objetivo da atividade

Praticar a criação, organização, acesso e exibição de dados armazenados em **arrays no PHP**, compreendendo a diferença entre arrays indexados, associativos e matrizes, além do funcionamento das estruturas `for` e `foreach`.
